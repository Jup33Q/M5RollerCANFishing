# prompt-rebuild — Pure-Prompt Rebuild Kit

[![中文说明](https://img.shields.io/badge/lang-%E4%B8%AD%E6%96%87-red)](README_zh.md)

A **pure-prompt rebuild kit** for the RollerCAN fishing simulator: no code included —
only the materials that cannot be regenerated from a prompt.

## Contents

| Path | Purpose |
|---|---|
| `ACTIVATE.md` | **One-shot activation prompt (EN)**: paste it verbatim into Kimi Code to rebuild the whole project from scratch ([中文](ACTIVATE_zh.md)) |
| `BLENDER-MODEL.md` | **Blender modeling prompt (Kimi K3, EN)**: rebuilds the reel model against the reference renders ([中文](BLENDER-MODEL_zh.md)) |
| `assets/fish/` | 7 pixel-fish PNGs (background-removed RGBA) — the single source of fish art for firmware sprites and Unity |
| `assets/model-ref/` | 4 reel-model reference renders (preview / preview_crank / axis_check / fbx_reimport_check) |
| `skills/flux-klein/` | Local text-to-image skill (for regenerating or adding fish art) |
| `skills/unity-cli-pipeline/` | Unity CLI / batch-mode operations & troubleshooting skill |
| `docs/` | The 5 build plans (protocol, parameters, every recorded pitfall — read before rebuilding) |

## How to use

1. Create an empty directory as the workspace.
2. Copy the whole `prompt-rebuild/` folder into it.
3. Open Kimi Code and paste the **entire content of `ACTIVATE.md`** as the first
   message.
4. The agent rebuilds per spec: both firmware projects, the RollerFlasher uploader,
   the Unity project, and the Blender model script — then verifies each with the
   stated compile checks. Flashing and Play-testing are yours to run.
5. For the reel model alone, use `BLENDER-MODEL.md` with Kimi K3 (it drives the
   model against the reference renders until the preview matches).

## Notes

- The code is deliberately absent: the spec in ACTIVATE.md plus the build records in
  docs/ are sufficient for an agent to reimplement everything. The fish art cannot be
  regenerated by prompt, so it ships with the kit.
- macOS only: the toolchain (RollerFlasher, Steam build of Blender, the verified
  Unity setup) works on macOS only.
